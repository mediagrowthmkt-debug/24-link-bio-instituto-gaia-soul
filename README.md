# Link in Bio — Instituto Gaia Soul

Página de links (link in bio / linktree) do **Instituto Gaia Soul**, em HTML único.

Repositório **independente** do site principal do Instituto Gaia (`instituto-gaia`).

## Estrutura
- `index.html` — página completa (estilo, scripts e bloco `CONFIG` no topo do `<script>`).
- `assets/` — logos oficiais e capas dos e-books.

## Editar
Tudo é editável no bloco `CONFIG` dentro do `<script>` em `index.html`: links, e-books,
redes sociais, WhatsApp, mensagem do voluntário e endpoint do CRM.

## Publicação
GitHub Pages (branch `main`, raiz do repositório).
